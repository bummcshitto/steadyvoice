# SteadyVoice 1.4.0 download

Open `SteadyVoice-1.4.0-Windows-x64.zip` on this branch and click **Download raw file**. Sign in to GitHub with access to this private repository if prompted.

The ZIP contains the Windows x64 DLL, complete source, setup guide, screenshots, and validation results. Start with **Smooth boost** for Adaptive RMS On, five configurable RMS time constants, a median range, and 5 ms lookahead with Guard On.

The accompanying `.sha256` file contains the archive checksum. The ZIP also contains a SHA256 manifest for every packaged file.

This separate branch provides the completed archive after the chat artifact download failed. It does not change the main branch.
